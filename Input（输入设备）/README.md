# Introduction（介绍）
### DisKey.bat
Funciton:Disable the keyboard of the laptop  
功能:禁用笔记本键盘
### EnKey.bat
Funciton:Enable the keyboard of the laptop  
功能:启用笔记本键盘
### Disable_Touchpad.bat
Funciton:Disable touchpad/touchscreen  
功能:禁用触控板/触摸屏
### Enbale_Touchpad.bat
Funciton:Enable touchpad/touchscreen  
功能:启用触控板/触摸屏
### Reload_Touchpad.bat
Funciton:Reload the Touchpad
功能:重载触控板
