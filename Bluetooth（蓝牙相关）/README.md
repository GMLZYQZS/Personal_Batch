## Introduction（介绍）
# BT_Receive.bat
Funciton:Open the Bluetooth receive file interface and hide the cmd.
功能：打开蓝牙接收文件界面并隐藏cmd框
# BT_Send.bat
Funciton:Open the Bluetooth send file interface and hide the cmd.
功能：打开蓝牙发送文件界面并隐藏cmd框
# Bluetooth_Connect.bat
Funciton:Open the Bluetooth connection interface.
功能：打开蓝牙连接界面
