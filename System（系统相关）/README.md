# Introduction（介绍）
### Check_Power.bat
Funciton:Check the current available status of the system
功能:查看系统当前可用状态
### OpenSoundSetting.bat
Funciton:Open the sound settings window
功能:打开声音设置窗口
### Restart_BIOS.bat
Funciton:Restart and enter the BIOS interface
功能:重启并进入BIOS界面
### SetDate.bat
Funciton:Set the date and disable the automatic update of time service
功能:设置日期并关闭时间自动更新服务
### SleepResult.bat
Funciton:Prepare a report on sleep research
功能:生成一份睡眠研究的报告
### TestMode.bat
Funciton:Enable Windows test signing mode
功能:开启Windows测试签名模式
